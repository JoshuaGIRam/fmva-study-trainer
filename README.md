# FMVA Study Trainer

Mobile-first PWA for FMVA preparation. It includes a 2026-aligned study blueprint, original practice questions, adaptive quiz flow, exam simulation, finance calculators and local progress tracking.

## Run locally
Open `index.html` in a modern browser. For the service worker/PWA install experience, serve the folder from a local web server or static host.

## iPhone
Deploy the folder to a static HTTPS host. Open the site in Safari and use **Share -> Add to Home Screen**.

## Content note
The app uses public CFI material to establish the current program/exam structure and creates original explanations/questions. It does not reproduce CFI's paid course materials or actual exam questions.
